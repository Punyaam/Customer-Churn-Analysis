# Customer Churn Analysis

This project analyzes telecom customer data to understand factors that influence customer drop-off.

## Objective
To identify patterns in customer behavior that contribute to customers leaving a service.

## Dataset
IBM Telco Customer Churn dataset containing 7,043 customer records and 21 features.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Analysis Performed
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Churn analysis based on contract type, tenure, and monthly charges
- Data visualization to support insights

## Key Insights
- Month-to-month contract customers show higher drop-off rates
- Customers with higher monthly charges are more likely to leave
- Long-term customers demonstrate higher loyalty
